Privacy Policy – Windowlit Agent

Last updated: 23 November 2026

Who uses this app

Windowlit Agent is a personal tool used only by the owner of the Windowlit YouTube channel. It is not a public service.

What data it accesses

With the owner's consent through Google's sign-in screen, the app accesses only the owner's own YouTube channel: video information (titles, descriptions, captions, comments) and channel analytics (views, watch time, audience data), using the scopes youtube.force-ssl and yt-analytics.readonly.

How the data is used

The data is used only to show the owner reports about the channel and to help prepare and manage the owner's own videos. Any change to the channel (upload, title or description edits, replies) is made only after the owner's approval.

Sharing and storage

The data is not sold, shared with or transferred to any third party. The access token is stored only on the owner's own computer. No data is used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service. Google's privacy policy: policies.google.com/privacy.

Revoking access

Access can be removed at any time from the Google Account security settings (myaccount.google.com/permissions).

Contact

Questions can be sent through the Windowlit YouTube channel.
