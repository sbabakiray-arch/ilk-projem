Windowlit Agent

A private helper tool for the Windowlit YouTube channel (cozy winter, rain and fireplace ambience).

Windowlit Agent is a small personal application used only by the owner of the Windowlit YouTube channel. It connects to the owner's own channel through Google's official YouTube Data API and YouTube Analytics API to:

  • read the channel's own statistics (views, watch time, audience retention);
  • prepare video titles, descriptions and translations;
  • upload the owner's own videos as private and schedule them, only after the owner approves.

It is not offered to the public and does not access any other channel.
